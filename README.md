# 📌 Project Overview

**Project Lifecycle Management Portal (PLMP)** is a MERN Stack based web application designed to manage Final Year Projects from initial idea submission to final evaluation.

The system provides a centralized platform where **Admins, Teachers, and Students** can collaborate efficiently. It helps universities manage project proposals, requirements, deliverables, evaluations, announcements, and project progress tracking.

# ⚙️ Installation & Setup


## Clone Repository

```bash
git clone https://github.com/SagheerAbbas041/Final-Year-Project.git
```


---

# Backend Setup


Navigate to backend folder:

```bash
cd Backend
```


Install dependencies:

```bash
npm install
```


Run backend server:

```bash
npm start
```


---

# Frontend Setup


Navigate to frontend folder:

```bash
cd Frontend
```


Install dependencies:

```bash
npm install
```


Run React application:

```bash
npm start
```
